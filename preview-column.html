    你好，世界 👋

    2026-08-22·分类：随笔·标签：#hello

    欢迎来到我的博客！这是第一篇文章，用来验证整个博客流程。从此以后，每一次思考都多了一个安放的地方。

    写博客的约定

    先立几条简单的规矩，让以后每一篇都顺顺利利：

    • 文章放在 _posts/ 目录，文件名格式：YYYY-MM-DD-标题.md
    • 文件开头的 --- 之间是 front matter，必须包含 title 和 date
    • 用 categories（分类）和 tags（标签）给文章归类，顶部导航会自动聚合
    • 写完 git push 到 main 分支，GitHub Actions 会自动构建部署

    写作的第一要义，是先把一句话说清楚，再想它漂不漂亮。

    写一篇示例代码

    def hello(name: str) -> str:
    return f"Hello, {name}!"
