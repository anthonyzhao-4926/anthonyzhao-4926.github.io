## 写博客的约定

- 文章放在 `_posts/` 目录，文件名格式：`YYYY-MM-DD-标题.md`
- 文件开头的 `---` 之间是 front matter，必须包含 `title` 和 `date`
- 用 `categories`（分类）和 `tags`（标签）给文章归类，顶部导航的「分类」「标签」页会自动聚合
- 写完 `git push` 到 `main` 分支，GitHub Actions 会自动构建部署

## 写一篇示例代码

```python
def hello(name: str) -> str:
    return f"Hello, {name}!"

print(hello("zhaoxin"))
```
